## QuickLoadout 1.0.0

First release, for Minecraft 1.21.8 - 1.21.11 (one jar).

- 4 hotbar loadouts: save with L + 1-4, recall with L + F1-F4
- Recall pulls items from the main inventory, other hotbar slots and the offhand, and merges stacks back to the saved amount
- Missing items are listed above the hotbar with their display name and amount
- Small caps messages: chat only when saving, action bar when recalling
- Items match by type and components (name, enchantments, potions...), ignoring durability, repair cost and container contents
- Works on any server: only normal inventory clicks, nothing needed on the server
- F1, F3, the number keys and the Advancements key keep their vanilla behaviour
- All keys can be changed in Controls → Key Binds → Hotbar Settings
- English and Italian translations
